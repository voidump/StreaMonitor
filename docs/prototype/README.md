# StreaMonitor 控制台 UI 原型

`console.html` 是一个**可交互、纯前端**的控制台改版原型（模拟数据，无后端依赖、无构建步骤）；已由单文件拆分为 `html + css + 多个 js` 的可维护结构（见「文件结构」）。

## 运行

```bash
python3 -m http.server 8901 --directory docs/prototype
# 打开 http://localhost:8901/console.html
```

或直接用浏览器打开 `console.html`（字体来自 Google Fonts，离线时回退系统字体）。

## 结构与交互（全部可实际操作）

- **录播总览**：状态芯片（录制中/在线/私密/限流/错误/受限/离线/长期离线/已暂停/已停止录播，语义对齐 `streamonitor.enums.Status`）、站点徽章、7 天上线规律 sparkline、文件数/大小/最近检查/添加日期；站点筛选为独立芯片行（仅显示有主播的站点，带数量）+ 状态组 + 关键词筛选；列头排序；录制中行有红色侧边条与实时字节数；<920px 自动切卡片流；每行/每卡片操作齐全（暂停/恢复录播、打开主播主页、停止录播/彻底删除）；行/卡片复选框 + 全选可多选，选中后底部浮出批量操作条，支持批量「暂停录播」「恢复录播」「停止录播」与「彻底删除」（停止录播/彻底删除带确认弹窗）。
- **添加主播**：主区内联表单。粘贴 URL 实时识别站点+用户名（试 `https://chaturbate.com/cutelily/`，会命中"本地已有 3 个视频"的模拟场景）；不支持的域名给出明确报错；重复添加直接跳转已有主播详情；备用"站点+用户名"手动模式。
- **录制详情**：进入即自动装载最新录制文件到播放器（模拟播放，可播/停/拖动，从上次观看进度续播）；缩略图网格显示**日期+星期与时间（分开展示）**、时长、大小、观看进度条、上次观看；单文件下载/删除（行内确认），播放器控制条也有删除按钮，**删除后自动连播下一个更早的录制**（删到最旧则回退较新的，播放中删除不中断）；临时文件区支持单个修复/全部修复/清理失效。
- **播放器（重造）**：拖动 seek + 悬浮时间提示、`-30/-5/+5/+30` 秒快跳、上一/下一（更早）视频、倍速 0.5–2×、音量与静音、播放到底自动连播下一个、按 `watchPct` 续播；倍速/音量/静音写入 localStorage 持久化。
- **标记与批量处理**：`M` 键标记当前播放视频（缩略图上也有标记按钮），标记项带琥珀色边框与徽章；录制文件区可在「全部 / 已标记」列表视图间切换；有标记时底部浮出批量操作条（数量+总大小），批量删除带确认弹窗，可一键清除标记。播放器快捷键完整且可在设置页改绑（默认：`空格` 播放/暂停、`← →` ±5s、`Shift+← →` ±30s、`↑ ↓` 音量、`PgUp/PgDn` 或 `[ ]` 上/下一个、`X` 静音、`M` 标记、`Esc` 关闭确认/弹窗）。
- **历史记录**：被「彻底删除」的主播写入历史页，展示头像/名称/站点徽章/添加与删除时间，可「重新添加」（恢复录播并打开详情）、打开主页或从历史移除。
- **移除主播**：弹窗二选一——「停止录播，保留本地文件」：条目保留在列表中，状态变为**已停止录播**（新状态+筛选项，行置灰，可随时恢复录播）；「移除并删除所有本地文件」：红色危险确认后彻底移除。已停止的主播再次移除时只提供删除文件这一项。
- **上线规律**：详情页右栏 7×24 热力图 + 常见时段/平均时长/近 7 天在线/活跃度。
- **设置**：中/英文切换（localStorage 持久化）；**播放器快捷键配置**——点击键位徽章后按任意键改绑，支持冲突检测与「恢复默认」，绑定写入 localStorage；预留自动清理、刷新频率位。

## 文件结构

```
console.html          # 入口：DOM 骨架 + 资源引用（无内联脚本）
css/console.css       # 全部样式与响应式断点（920 表格↔卡片、1080 详情双↔单栏、760/860 移动压缩）
js/
  i18n.js             # 全局错误提示浮层 + 中英词典与 t()
  data.js             # 模拟数据、站点表 SITES、状态枚举 STATUS、缩略图/头像生成
  store.js            # 状态与路由 nav()、历史记录、快捷键读写、toast
  main.js             # URL 解析、添加主播、master render() 与事件总线、播放/删除/批量逻辑
  player.js           # 播放器渲染 + 可配置快捷键引擎 + 播放偏好持久化
  views/
    dashboard.js      # 总览表格/卡片、多选批量操作、历史视图
    detail.js         # 录制详情、缩略图网格、临时文件区、已标记浮条
    settings.js       # 设置页 + 快捷键编辑器
    modal.js          # 移除/批量/历史等弹窗渲染
```

> 纯静态、无构建步骤：`console.html` 顺序加载各脚本，函数/状态挂在全局作用域，`render()` 为唯一渲染入口。

## 设计基调

深色、克制、信息密度优先：IBM Plex Sans/Mono，单一功能强调色（钢蓝），状态色只用于状态语义；侧栏导航 + 顶部操作 + 内容区自滚动的全高应用布局；断点 920px（表格↔卡片）、1080px（详情双栏↔单栏）、760/860px（移动压缩）。

## 落地为真实功能时的后端缺口（阶段二已收口）

原型已落地为真实的 `webui` 皮肤：静态前端 + `/api/v2/...` JSON 后端（挂载在所有皮肤上）。
以 `STRMNTR_SKIN=webui python3 Downloader.py` 启用。下表记录各能力的落地状态。

| 原型能力 | 落地状态 | 说明 |
|---|---|---|
| URL 识别站点/用户名 | ✅ 已落地 | 前端 SITES 表识别，`POST /api/v2/streamers`（site+username）新增 |
| 观看进度/上次观看 | ✅ 已落地 | 前端 localStorage（`watchPct`） |
| 添加时发现本地已有视频 | ✅ 已落地 | `cache_file_list` 扫描下载目录，`GET /api/v2/streamers/<site>/<user>` 返回真实文件列表 |
| 中英 i18n | ✅ 已落地 | `webui` 皮肤前端词典（localStorage 持久化） |
| 停止录播但保留条目（monitorState） | ✅ 已落地 | config 增加 `monitorState`；`stop-recording`/`reactivate` 端点区分「暂停」与「停止录播」 |
| 视频标记状态 | ✅ 已落地 | 前端 localStorage |
| 曾关注历史记录 | ✅ 已落地 | `history.json` 持久化 + `GET/POST/DELETE /api/v2/history`（readd/移除） |
| 快捷键改绑 / 播放偏好 | ✅ 已落地 | 前端 localStorage |
| 倍速 / 音量 / 续播进度 | ✅ 已落地 | 真实 `<video>` + 前端 localStorage |
| 视频播放 / 拖动进度条 seek | ✅ 已落地 | 真实 `<video>`（`src=/video/...`），后端 `send_from_directory` 支持 HTTP Range（206 Partial Content）实现拖动 seek |
| 录制中文件保护 | ✅ 已落地 | 删除正在录制的文件时 `DELETE /api/v2/.../videos/<file>` 返回 409，前端同时灰显 |
| 批量操作 | ✅ 已落地 | `POST /api/v2/batch`（暂停/恢复/停止录播/彻底删除） |
| 缩略图/抽帧 | ⬜ 仍为占位 | 网格缩略图仍为前端生成占位；真实播放走 `<video>`，未接 ffmpeg 抽帧缓存 |
| 上线规律热力图 | ⬜ 仍为模拟 | 尚未持久化每次状态检查的在线采样 |
| 临时文件修复 | ⬜ 未落地 | 尚无 ffmpeg remux（`-c copy`）任务端点 |
